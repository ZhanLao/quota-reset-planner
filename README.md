# Quota Reset Planner

Local-first PWA for scheduling quota resets, expiring reset cards, valued tasks, and uncertain extra resets without assuming future knowledge.

Chinese documentation: [README_zh.md](./README_zh.md)  
Mathematical model: [MATHEMATICAL_MODEL.md](./MATHEMATICAL_MODEL.md)

```powershell
npm ci
npm run test:complex
npm test
npm run build
npm run test:e2e
```

MIT licensed. Personal planning data stays in the browser unless the user explicitly exports JSON.
