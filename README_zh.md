# 额度重置策略工作台

一个本地优先、可离线安装的 PWA，用来联合安排：剩余额度百分比、自然重置周期、会改变自然日期的卡片、确定性强制重置和不确定额外重置。

它首先最大化规划终点前**真正使用掉的累计百分比**；高价值任务只在总使用量相同的方案中决胜。程序不登录 ChatGPT、不读取账号，也不会替你自动点击重置。

## 你应该先想什么

遇到额度排程问题时，先依次确认：

1. 重置是覆盖余额，还是在余额上累加？本程序默认覆盖到满额。
2. 用卡是否把下一自然重置改成“用卡时刻 + 周期”？每张卡可以单独设置。
3. 当前剩余额度百分比和下一自然重置究竟是多少？只知道上次重置日期不够。
4. 未来活动的概率是否可信？未知概率不会被擅自当成 50%。
5. 强制重置是未来确定事件，还是刚刚发生后需要从当前状态重新规划？

## 使用环境与保存位置

- 开发环境：Node.js 24 LTS、npm、现代 Chrome/Edge/Firefox。
- 目标源码位置：`D:\Github_Programs\quota-reset-planner`。
- 网页数据：保存在当前站点所属的浏览器 IndexedDB 中，物理文件由浏览器管理，请勿手动编辑。
- 跨浏览器或跨设备：用页面右上角导出 JSON，再在另一设备导入。
- GitHub Pages：只发布静态程序，不接收或保存你的计划数据。

PWA 首次加载必须通过 HTTPS 或 localhost。不要直接双击 `dist/index.html`，否则 Service Worker 与 WebAssembly 可能因浏览器安全规则无法工作。

## 参数与结果

- 输入只接受“剩余百分比”：满额为 `100%`；若官方页面显示已使用比例，请填写 `100%-已使用%`。
- 累计使用允许超过 `100%`，结果同时显示累计百分比和等价满额次数。
- 规划区间采用 $[t_0,T)$，终点时刻不再产生使用价值。
- 卡片可用条件是 $a_j\le t<e_j$，失效时刻本身不可使用。
- 同刻顺序为：自然重置 → 确定性强制重置 → 已观察额外事件 → 手动用卡 → 本区间使用。
- 未来确定的强制重置可以提前加入；刚刚发生的意外重置使用“从此刻重规划”，余额变为 `100%`，自然日期和后续用卡计划一起重算。
- 默认手动动作网格为 1 小时；15/30 分钟更细但更慢，3 小时更快但误差更大。
- 高价值任务默认为空；任务允许拆分，但不会以牺牲累计使用量为代价。
- 概率完整时同时给期望最优和保底策略；概率未知时只给保底及各情景结果。
- “快速计算当前速度”只求当前 $D$；只有点击“比较使用速度”才运行 2/2.5/3 等样本。
- 结果顶部的“重置卡使用计划”明确列出日期、卡名、适用条件、使用前余额和新的自然重置日。

### 为什么旧版求解较慢

旧版默认对多个使用速度分别求解，而且每个策略还要依次完成多个目标层级；概率完整时又会同时计算期望与保底。V2 默认只算当前速度，无任务时跳过任务价值层，无不确定事件时不重复计算期望策略。界面会显示时间点、情景数、目标层数和总耗时；求解限时是每个目标层级的上限。

### 旧数据迁移

首次读取 schema v1 时，余额和任务需求按 `旧值 / 旧容量 × 100` 换算到 schema v2。旧结果会清除并要求重新求解；导出文件只写 v2，不加入哈希或 SHA 字段。

示例参数在 `examples/sep24-demo.json`。示例中的余额、时分和活动规则均为假设，不能替代账号页面的真实状态。

## 常见报错与修复

| 报错 | 原因 | 修改位置 | 修改方法 | 为什么可行 |
|---|---|---|---|---|
| `INPUT_INVALID` | 余额越界、时间窗颠倒、下一自然日期在过去或概率和错误 | 页面对应字段 | 按标红字段更新真实状态 | 模型只有在状态自洽时才有可实施含义 |
| `SCENARIO_LIMIT` | 互斥结果笛卡尔积超过上限 | 不确定事件 | 标记已观察结果、合并事件或分批运行 | 每减少一个未决分支都会减少整份模型副本 |
| `MODEL_TOO_LARGE` | 时域长、网格细、情景或任务过多 | 求解与精度 | 调成 1/3 小时、缩短时域或拆分敏感性 | 变量数随时间点和情景数增长 |
| `SOLVER_TIMEOUT` | MIP 在限时内未证明最优 | 求解限时与精度 | 使用标有间隙的可行解，或调粗网格重算 | 降低二进制动作数能缩小搜索树 |
| `WASM_LOAD_FAILED` | 直接双击 HTML、Pages 基础路径错误或旧缓存 | 启动方式/PWA 缓存 | 通过 localhost/HTTPS 打开并刷新站点缓存 | WebAssembly 和 Worker 需要正确的同源资源地址 |
| `STORAGE_UNAVAILABLE` | 隐私模式、浏览器禁用 IndexedDB 或配额不足 | 浏览器设置 | 允许站点存储并立即导出 JSON | JSON 是独立于浏览器数据库的恢复副本 |
| `SCHEMA_UNSUPPORTED` | JSON 损坏或来自更高格式版本 | 导入文件 | 使用本版本重新导出的文件 | 导入在覆盖当前项目之前完成整体校验 |
